# Sagheer Ahmed Landscape Gardening Maintenance LLC

This repository contains a static marketing landing page for a landscaping and garden maintenance business.

## Live site

Open the `index.html` file in a browser, or deploy the repo as a static site.

## Features

- Responsive layout for mobile and desktop
- Service cards and call-to-action sections
- WhatsApp contact buttons
- Cost estimator section
- Booking modal and inquiry form UI
